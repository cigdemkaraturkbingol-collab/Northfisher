# DenizHava Pro / Northfisher

Android balıkçı hava ve deniz uygulaması.

- Konum izniyle otomatik konum
- Gerçek hava verileri: Open-Meteo
- Deniz: dalga, periyot, yön, deniz sıcaklığı ve akıntı
- Balıkçı uygunluk puanı
- Yol riski: gerçek meteorolojik verilerden yağmur, kar, görüş, rüzgâr ve buzlanma değerlendirmesi
- API anahtarı gerekmez

> Deniz ve yol risk göstergeleri yardımcı tahminlerdir; resmî güvenlik/navigasyon uyarılarının yerine geçmez.
